# Onefold 视觉原型

两个文件：

| 文件 | 是什么 |
| --- | --- |
| `prototype/home-full.html` | **完整站点版**：导航、搜索、头条、筛选、事件流、右栏、页脚都在，只有桌面端。这个是要落地的骨架。 |
| `prototype/home.html` | 三个首页方向对比（A 编辑部 / B 瑞士网格 / C 暗色头条），只保留内容区，用来选风格。 |

```bash
open design/prototype/home-full.html
open design/prototype/home.html          # 默认 A
```

也可以用 `←` `→` 或底部胶囊切换。文件是纯 HTML + CSS，没有依赖，双击就行。

底部还有一颗 **玻璃 · 开/关**：关掉就是不含毛玻璃的纯色版，用来对比。这个状态也能通过 URL 复现：`?variant=b&glass=0`。

截图在 `screenshots/`，如果要贴进论文或给导师看，用这三张。

## 完整站点版包含什么

一个真实资讯站该有的骨架，都在 `home-full.html` 里：

- **吸顶导航**：品牌、栏目（今日 / AI / 综合科技 / 关于）、右侧搜索框，滚动时加深描边
- **头条区**：今日最重要的一条，独立版式，比列表事件大一号
- **筛选**：全部 / AI / 综合科技 / 未读 的胶囊
- **时间线**：按天分组，事件带主题标签、来源数、时间、收藏
- **右栏**：今日概览（事件数 / 来源数 / 更新时间）、报道最多的事件、来源排行、关于卡片，随页面滚动吸顶
- **页脚**：品牌与 slogan、浏览、资源、数据说明、版权与备案位
- **加载更早**：分页入口

## 只做桌面端

这个站没有移动端。实现上：

- `html { min-width: 1200px }`，窄屏直接横向滚动，**不做响应式降级**
- 版心 1300px；≥1600px 时放宽到 1440px（唯一的媒体查询）
- 不写任何 `max-width` 断点，不留移动端样式债务
- 自测分辨率：**1440 × 900** 和 **1920 × 1080**

一个现实提醒：很多答辩现场用 1024×768 或 1280×720 的投影。min-width 卡在 1200，1280 能看，1024 会横向滚动。答辩前问清楚投影分辨率，必要时把 min-width 降到 1024，或者用 1920 的笔记本直连。

## 三个方向的区别（不是配色区别，是结构区别）

| | 结构 | 信息重心 | 气质 | 风险 |
| --- | --- | --- | --- | --- |
| **A 编辑部** | 左日期栏 + 单列事件流 | 标题与摘要，第二眼才看到来源数 | 报纸、可信、耐读 | 偏保守，不够"科技" |
| **B 瑞士网格** | 通栏大标题 + 右侧大数字 + 强分隔线 | 来源数被放大成主视觉 | 设计感最强，像作品集 | 标题字号大，长中文标题容易顶格 |
| **C 暗色头条** | 一条主事件 + 紧凑列表 | 首条事件独占一屏 | 沉浸、夜间友好 | 暗色在答辩投影上容易发灰 |

三个都能叫"极简"，但**B 最像 2026 年**，A 最保险，C 最挑场景。

可以混：B 的顶部（大数字日期 + 强分隔线）配 A 的衬线标题，是我个人觉得最好的组合。

## 毛玻璃层

毛玻璃不是给页面加一层 `backdrop-filter` 就有的。**玻璃必须糊在东西上**，底下是纯色的话，玻璃等于一块半透明色块，看不出是玻璃。

所以结构分两层：

```
.scene   固定层：三团模糊光斑 + 细颗粒（毛玻璃要糊的就是它）
  └ .sheet  内容玻璃板：半透明 + backdrop-filter: blur(30px) saturate(145%)
```

```css
.scene{position:fixed;inset:0;z-index:0;pointer-events:none;overflow:hidden}
.glow{position:absolute;border-radius:50%;filter:blur(110px)}

.sheet{
  background:rgba(252,250,246,.60);          /* 亮色：不低于 .5 */
  border:1px solid rgba(255,255,255,.75);    /* 一圈高光边，玻璃的关键 */
  -webkit-backdrop-filter:blur(30px) saturate(145%);
  backdrop-filter:blur(30px) saturate(145%);
  box-shadow:0 44px 90px -52px rgba(72,52,32,.5);
}
```

四条注意事项：

1. **光斑别超过三个色相。** 三团以内、低饱和、`blur(90–120px)`。色相一多就从"高级"掉到"极光壁纸"。
2. **颗粒不能省。** 一层 `feTurbulence` 颗粒（opacity 3–5%）能消掉渐变的塑料感，这是"磨砂"和"渐变"的区别。
3. **文字对比度会被吃掉。** 亮色玻璃的不透明度别低于 0.5，否则正文发灰；暗色玻璃用 `rgba(255,255,255,.04)` 配 `rgba(255,255,255,.09)` 的边。
4. **性能。** `backdrop-filter` 在移动端和低端机上掉帧明显。只给整页板、固定导航、抽屉这类**大块固定区域**用，不要给每一行事件都加。所有用到的地方都套一层 `@supports` 降级。

还有一个实际的坑：**暗色玻璃在投影仪上会发灰**，对比度比显示器上低一截。如果答辩选 C 方案，务必提前在真实投影上过一遍。

## 共用的视觉规范

### 颜色

三套各自的 token，都只留一个强调色，且强调色只出现在"多源"这一个信息上：

```css
/* A 编辑部 */
--page:#EAE2D7;  --sheet:rgba(252,250,246,.60);  --ink:#17140F;  --muted:#6E675C;  --line:#E3DCD1;  --accent:#9C3B26;
/* B 瑞士网格 */
--page:#EAECEF;  --sheet:rgba(255,255,255,.62); --ink:#0B0B0B;  --muted:#6B6B6B;  --line:#111111;  --accent:#E2482C;
/* C 暗色头条 */
--page:#070709;  --sheet:rgba(255,255,255,.035); --ink:#E8E4DB;  --muted:#948F85;  --line:#1E1E21;  --accent:#C9A86A;
```

### 字体

```css
--serif: "Songti SC", "STSong", "Noto Serif CJK SC", "Source Han Serif SC", serif;
--sans:  "PingFang SC", -apple-system, "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
--mono:  "SF Mono", ui-monospace, Menlo, monospace;
```

**一个必须提前处理的问题**：`Songti SC` 和 `PingFang SC` 是 macOS 自带，Windows 上都没有。如果答辩用 Windows 笔记本，衬线标题会掉到「宋体」，小字号下笔画发糊，高级感全没。

解决办法：自托管一份 **思源宋体（Source Han Serif SC）** 的子集 woff2，只保留 GB2312 常用字，体积能压到 1–2MB；`font-display: swap`。这件事建议在 M3 前端开工第一天就做，不要留到答辩前。

### 字号与节奏

| 用途 | A | B | C |
| --- | --- | --- | --- |
| 事件标题 | 24px / 1.55 宋体 600 | 29px / 1.4 黑体 600 | 17px / 1.6 黑体 400（头条 43px 宋体） |
| 摘要 | 14.5px / 1.95 | 13.5px / 1.95 | 15px / 1.95 |
| 元信息 | 11.5px / 字距 .05em | 11px / 字距 .2em | 10.5px 等宽 |
| 区块间距 | 30px | 34px | 26px |

中文正文行高 **1.9**，字距 **0.01em**，**不要用 `text-align: justify`**——中文两端对齐会把字距拉得忽宽忽窄，这是廉价感的主要来源之一。

### 线条与圆角

- 分隔线一律 **1px**，颜色取 `--line`，不用阴影、不用卡片
- 圆角为 **0**，只有底部切换胶囊是 999px
- B 的分隔线用纯黑 1px，是唯一允许"重线"的地方

## 五条硬规则

想要"高级感"，其实只要守住这五条，比堆任何装饰都有效：

1. **不用卡片。** 卡片 + 阴影是后台管理系统的东西。信息之间用一根线隔开就够，线比卡片贵。
2. **一屏只有一个强调色。** 而且它必须挂在产品的核心信息上——「5 家媒体」。颜色一多，廉价感立刻回来。
3. **衬线标题 + 黑体正文 + 等宽数字。** 三种字体各司其职，这是"编辑感"的来源。数字用 `font-variant-numeric: tabular-nums`。
4. **留白要大于内容。** 事件之间至少 26px，页面左右至少 48px。宁可少放两个事件，也不要挤。
5. **动效只做三件事**：淡入（opacity）、变色、位移不超过 2px。时长 150–350ms，曲线用 `ease-out`。不要弹跳、不要缩放。

## 还没做的

- **事件详情页**。那才是这个产品真正要证明的地方（一个事件下 6 家媒体并排），首页只是入口。
- 只在 1440 和 1920 两档调过，1280 没细看。
- 收藏 / 已读的交互状态、空状态、加载态。
- 搜索页。

先定方向，再往下做详情页——详情页会把方向里的问题放大，选错了返工更贵。
